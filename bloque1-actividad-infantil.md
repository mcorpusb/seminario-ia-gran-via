# Actividad · Crear un cuento o cómic educativo
{: .fs-7 }

Crea un cuento, un cómic o una narración visual para explicar un contenido de Secundaria o Bachillerato, revisarlo con criterio docente y convertirlo en un recurso útil para el aula.
{: .fs-5 .fw-300 }

---

> **Protege la privacidad del alumnado**
>
> No introduzcas nombres reales, diagnósticos, situaciones familiares, información sanitaria, necesidades individuales identificables, fotografías del alumnado ni otros datos personales del grupo.
>
> Para contextualizar la actividad basta con indicar el curso, el nivel, la materia, el tema, la duración aproximada, los objetivos y el tipo de grupo. No hace falta señalar el número exacto de estudiantes salvo que sea pedagógicamente necesario.
{: .warning }

## 🎯 Objetivo

Crear y revisar un cuento, un cómic o una narración visual para una situación real de Secundaria o Bachillerato, transformarlo en un recurso claro para el aula y preparar una breve orientación de uso para el profesorado o el grupo, utilizando IA con criterio y sin compartir datos personales.

## 🧩 El reto

Piensa en un tema o situación que estés trabajando o vayas a trabajar próximamente en Secundaria o Bachillerato: convivencia, ciudadanía digital, educación en valores, uso responsable de la tecnología, literatura, historia, igualdad, salud, orientación o cualquier otro contenido adecuado.

Utiliza el asistente de IA que tengas disponible y cuya utilización sea adecuada para la tarea. Puede ser Copilot Chat, ChatGPT, Gemini, Kimi u otra alternativa del [Radar de herramientas]({{ '/primeros-pasos/herramientas-que-utilizaremos.html#radar' | relative_url }}). No necesitas utilizar una cuenta personal.

Seguirás este recorrido:

**Necesidad de aula → idea narrativa → revisión docente → recurso visual → orientación final → reflexión**

Al finalizar tendrás:

- un cuento breve, cómic o secuencia narrativa revisada;
- un pequeño recurso visual o una secuencia de escenas;
- una orientación breve para el profesorado o el grupo;
- una reflexión sobre el proceso.

## Define la necesidad de aula
{: id="1-define-la-necesidad-de-aula" }

Completa esta mini ficha sin incluir información identificativa:

```text
Tema:
Curso:
Objetivo:
Duración aproximada:
Tipo de grupo:
Mensaje o aprendizaje que quieres trabajar:
```

## Crea un primer borrador del cuento
{: id="2-crea-un-primer-borrador-del-cuento" }

Adapta este prompt con la información de tu ficha:

```text
Quiero crear un cuento breve para una actividad de Secundaria o Bachillerato.

Curso: [ESO/Bachillerato]
Tema: [completa]
Objetivo: [completa]
Materia o ámbito: [completa]
Interés general del grupo: [completa]

Escribe un texto de unas 250-400 palabras, pensado para leerse en clase o convertirse en una secuencia visual.

Criterios:
 - vocabulario claro y adecuado al nivel;
 - una estructura narrativa reconocible;
 - un personaje o situación cercana al alumnado;
 - una situación fácil de comprender;
 - un tono no infantilizado;
 - una conexión evidente con el contenido curricular;
- una pregunta final para abrir una breve conversación o reflexión.

No incluyas datos reales del alumnado ni inventes información sobre mi grupo.
```

Si lo prefieres, puedes pedir una versión con tono más literario o más divulgativo, según el uso que quieras darle.

### Ejemplo: «El rumor del laboratorio»

Este ejemplo muestra una posible situación de trabajo de valores y convivencia; no es una plantilla obligatoria.

> En el laboratorio del instituto circula un rumor: una aplicación de IA puede resolver todos los ejercicios del trimestre. Una estudiante decide probarla y se da cuenta de que algunas respuestas son útiles, pero otras son imprecisas o inventadas. Su grupo debate entonces qué significa realmente aprender, cuándo conviene usar la herramienta y cuándo es mejor no delegar.
>
> **Pregunta para el aula:** ¿Qué parte del trabajo seguirías haciendo tú aunque tuvieras una IA muy buena?

La finalidad no es hacer desaparecer el conflicto, sino reconocerlo, expresarlo y usarlo como punto de partida para la reflexión crítica.

## Revisa y mejora el cuento
{: id="3-revisa-y-mejora-el-cuento" }

La primera respuesta de la IA es un borrador. Revisa:

- ¿El vocabulario es adecuado?
- ¿La longitud funciona para el tiempo de clase previsto?
- ¿El mensaje es pedagógicamente adecuado?
- ¿Hay estereotipos o simplificaciones excesivas?
- ¿La situación se representa con respeto?
- ¿La IA ha inventado algo que no pediste?
- ¿La pregunta final puede generar una conversación real?

Puedes refinarlo con instrucciones breves, por ejemplo:

```text
Reduce el texto a 280 palabras sin perder la idea principal.
```

```text
Haz las frases más claras y directas.
```

```text
Sustituye esta parte por una situación más cercana al alumnado de ESO o Bachillerato.
```

```text
Evita presentar la tecnología como una solución mágica o como una amenaza absoluta.
```

```text
Introduce una frase o idea que pueda usarse como idea-fuerza en clase.
```

## Convierte el cuento en un recurso visual
{: id="4-convierte-el-cuento-en-un-recurso-visual" }

Esta es una primera aproximación al proceso **texto → escenas → imágenes → recurso visual**.

### Planifica el cómic o cuento ilustrado

Cuando el cuento esté revisado, pide a la IA que seleccione entre 4 y 6 escenas esenciales. Puedes utilizar este prompt:

```text
Quiero convertir este texto revisado en un pequeño cómic o narración visual para Secundaria o Bachillerato.

Divídelo en 6 escenas esenciales.

Para cada escena indica:
- qué ocurre;
- qué personaje aparece;
- qué emoción o acción debe verse;
- qué elementos principales debe tener la imagen;
- qué frase breve puede acompañarla.

No añadas acontecimientos nuevos.
Mantén al personaje principal reconocible entre escenas.

[Pega aquí el texto revisado]
```

### Una forma sencilla de describir una imagen

**PERSONAJE + ACCIÓN + ESCENARIO + ESTILO + DETALLE IMPORTANTE**

Para mantener la continuidad visual entre escenas, describe al personaje principal de forma similar en todas las imágenes.

Utiliza la herramienta de generación de imágenes que tengas disponible. Por ejemplo, puedes usar el generador incluido en alguno de los asistentes compatibles o una herramienta específica. Consulta el [Radar de herramientas]({{ '/primeros-pasos/herramientas-que-utilizaremos.html#radar' | relative_url }}) si necesitas una alternativa.

> **Antes de utilizar el cómic, comprueba:**
>
> - la coherencia del personaje entre escenas;
> - la ausencia de elementos extraños o de manos, objetos y escenarios incorrectos;
> - la adecuación cultural y la ausencia de estereotipos;
> - la claridad visual y la adecuación al nivel del grupo;
> - que no haya imágenes que puedan distraer innecesariamente;
> - la legibilidad de cualquier texto incorporado.
{: .warning }

Revisa siempre el texto generado dentro de las imágenes: puede contener errores ortográficos o palabras inventadas. Cuando sea posible, añade el texto después con una herramienta de edición o presentación si así mejoras la legibilidad.

## Prepara una breve orientación de uso
{: id="5-prepara-una-comunicación-para-las-familias" }

Parte del texto final revisado y adapta este prompt:

```text
Redacta un borrador breve para explicar al profesorado o al grupo de clase que estamos trabajando [tema].

Incluye:
- qué estamos trabajando;
- cómo lo hemos trabajado mediante un cuento o un cómic;
- una propuesta breve para comentar en clase o en tutoría;
- un agradecimiento.

Utiliza un tono cercano, claro y profesional.
No añadas información personal ni datos que no te haya proporcionado.
```

Si en tu contexto hay diversidad lingüística, pide una versión especialmente clara y revisa el resultado.

También puedes solicitar una versión en valenciano o bilingüe. Revísala antes de utilizarla, especialmente en lo relativo a la terminología educativa y administrativa. Puedes consultar los recursos lingüísticos de la [Acadèmia Valenciana de la Llengua](https://www.avl.gva.es/).

## 📦 Entregable

Presenta:

- el cuento final revisado;
- el pequeño cómic, cuento ilustrado o secuencia visual;
- la nota a familias revisada;
- una muestra breve del proceso de trabajo con IA —el prompt inicial y uno o dos cambios relevantes son suficientes—;
- la reflexión final.

Puedes utilizar un PDF, documento, presentación u otro formato admitido. **El formato de entrega será el indicado en Aules.**

## 💭 Reflexión final

Responde brevemente:

- ¿Qué cambiaste respecto a la primera propuesta de la IA?
- ¿Qué decisión pedagógica mantuviste bajo tu criterio?
- ¿Qué información decidiste no compartir?
- ¿Utilizarías realmente este recurso con tu grupo? ¿Qué adaptarías?

## 🌱 Aplicación en el aula

Puedes utilizar el cuento en una asamblea y el cómic como apoyo visual. Si tiene sentido en tu contexto, comparte la nota con las familias por el canal habitual del centro.

## 🔁 Variante opcional

Crea una secuencia visual de una rutina de aula, por ejemplo, lavarse las manos, recoger los materiales o prepararse para salir al patio. Revisa que cada paso sea claro, adecuado y coherente con la rutina real. Si utilizas pictogramas, recurre a recursos apropiados y comprueba que su significado sea válido para tu contexto.

En el **Bloque 3 · Generación Multimodal** profundizaremos en la creación y combinación de recursos visuales, audio, vídeo e infografías.
