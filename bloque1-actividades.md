# Laboratorio de prompts · Elige tu reto docente
{: .fs-7 }

Aprender a utilizar la inteligencia artificial no consiste solo en hacer preguntas, sino en aprender a formularlas, revisar las respuestas y tomar decisiones pedagógicas. Elige una de estas propuestas y descubre cómo mejora el resultado cuando incorporas contexto, objetivos y criterios claros.

**Diez alternativas: elige un reto.** Puedes explorar más de forma voluntaria; no son diez tareas obligatorias. Reserva **15–20 minutos de práctica docente**. La duración de la sesión que diseñarás para el alumnado es distinta y se indica en cada prompt.

{% include prompt-lab-privacy.html %}

## Un proceso compartido

**Petición inicial → prompt pedagógico → comparación → iteración → decisión docente.** En cada reto concretarás contexto educativo, alumnado destinatario, objetivo de aprendizaje, restricciones y formato de salida.
