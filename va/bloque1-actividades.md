# Laboratori de prompts · Tria el teu repte docent
{: .fs-7 }

Aprendre a utilitzar la intel·ligència artificial no consistix només a fer preguntes, sinó a aprendre a formular-les, revisar les respostes i prendre decisions pedagògiques. Tria una d’estes propostes i descobrix com millora el resultat quan incorpores context, objectius i criteris clars.

**Deu alternatives: tria un repte.** Pots explorar-ne més de manera voluntària; no són deu tasques obligatòries. Reserva **15–20 minuts de pràctica docent**. La duració de la sessió que dissenyaràs per a l’alumnat és diferent i s’indica en cada prompt.

{% include prompt-lab-privacy.html %}

## Un procés compartit

**Petició inicial → prompt pedagògic → comparació → iteració → decisió docent.** En cada repte concretaràs context educatiu, alumnat destinatari, objectiu d’aprenentatge, restriccions i format d’eixida.
